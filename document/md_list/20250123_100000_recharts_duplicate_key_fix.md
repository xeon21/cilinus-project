# Recharts Duplicate Key Warning Fix

## Issue
React is showing duplicate key warnings for tick elements generated by Recharts:
```
Warning: Encountered two children with the same key, `tick-1753220524958-104.1571152642714-104.1571152642714`
```

## Root Cause
The issue occurs in `StatusHistoryChart.tsx` where the XAxis is configured with:
- `scale="time"`
- `type="number"`
- Dynamic data that might have duplicate timestamps

## Solution

### Option 1: Add unique tick configuration (Recommended)
Add `tick` prop with unique key generation to XAxis:

```tsx
<XAxis
  dataKey="time"
  scale="time"
  type="number"
  domain={['dataMin', 'dataMax']}
  tickFormatter={timeFormatter}
  stroke="#95a5a6"
  fontSize={12}
  tick={(props) => {
    const { x, y, payload } = props;
    return (
      <text
        x={x}
        y={y}
        fill="#95a5a6"
        fontSize={12}
        textAnchor="middle"
        dy={16}
      >
        {timeFormatter(payload.value)}
      </text>
    );
  }}
/>
```

### Option 2: Ensure unique time values in data
Filter out duplicate timestamps when generating data:

```tsx
const data = history.map(log => ({
  time: new Date(log.timestamp).getTime(),
  memory: log.memory,
  disk: log.disk
})).filter((item, index, self) => 
  index === self.findIndex((t) => t.time === item.time)
);
```

### Option 3: Add interval prop to control tick generation
```tsx
<XAxis
  dataKey="time"
  scale="time"
  type="number"
  domain={['dataMin', 'dataMax']}
  tickFormatter={timeFormatter}
  stroke="#95a5a6"
  fontSize={12}
  interval="preserveStartEnd"
/>
```
