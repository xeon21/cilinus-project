## 🔐 JWT 인증 개선 (2025-01-21)

### JWT 환경변수 설정
- **목적**: 하드코딩된 JWT secret을 환경변수로 이동
- **수정 파일**: 
  - `auth.modules.ts`: JwtModule.registerAsync 사용
  - `jwt.strategy.ts`: ConfigService로 JWT_SECRET 로드
- **환경변수**: 
  - `JWT_SECRET`: JWT 토큰 서명 키
  - `JWT_EXPIRES_IN`: 토큰 만료 시간 (예: 7d)

### JWT Secret 생성 방법
```bash
# Node.js 사용 (권장)
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"

# OpenSSL 사용
openssl rand -hex 64
```

### JWT 설정 확인 로깅
- `auth.service.ts`에 JWT 설정 로깅 추가
- 보안을 위해 JWT_SECRET은 처음 10자만 표시

## 🗄️ 데이터베이스 설계 및 구축

### RBAC 기반 사용자 권한 시스템
- **구조**: 6개 주요 테이블
  - users (사용자)
  - roles (역할)
  - permissions (권한)
  - user_roles (사용자-역할 매핑)
  - role_permissions (역할-권한 매핑)
  - user_permissions (사용자별 직접 권한)

### 시스템 역할 5개
1. **super_admin**: 전체 시스템 관리
2. **admin**: 일반 관리 기능
3. **manager**: 프로젝트 관리
4. **editor**: 콘텐츠 편집
5. **viewer**: 읽기 전용

### 전체 데이터베이스 스키마
- **총 14개 테이블** 구축
- ESL 장치 관리, 프로젝트 관리, 리소스 모니터링 포함
- 모든 테이블에 타임스탬프 및 인덱스 적용
