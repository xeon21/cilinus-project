핵심 테이블 관계 설명

1. 계층적 조직 구조

organizations 테이블은 자기 참조(self-referencing) 구조로 무제한 계층을 지원합니다.

  • 본사(headquarters) → 지점(branch) → 매장(store) 구조
  • 지도 표시를 위한 위치 정보 포함 (latitude, longitude)
  • path 컬럼으로 계층 경로 최적화

2. 템플릿 시스템 분리

디바이스 레이아웃과 태그 디자인을 독립적으로 관리하는 이원화된 템플릿 시스템

  • device_templates: 화면 분할 레이아웃 (2x2, 1x4 등)
  • tag_templates: 개별 가격표 디자인
  • 유연한 조합으로 다양한 디스플레이 구성 가능

3. 디바이스-태그-상품 관계

하나의 디바이스에 여러 태그를 표시하는 구조

  • esl_devices: 물리적 디바이스 정보
  • price_tags: 디바이스 내 개별 태그 (위치, 크기 정보)
  • products: 태그에 표시될 상품 정보

인덱스 전략

성능 최적화를 위한 주요 인덱스

  • 계층 탐색: idx_organizations_parent, idx_organizations_path
  • 지도 표시: idx_organizations_location, idx_organizations_city_district
  • 디바이스 관리: idx_devices_org_status, idx_devices_template
  • 태그 조회: idx_price_tags_device, idx_price_tags_product
  • 상품 검색: idx_products_org_sku, idx_products_category

데이터 무결성 규칙

주요 제약 조건

  • Cascade Delete: 디바이스 삭제 시 관련 태그 자동 삭제
  • Set Null: 상품 삭제 시 태그의 product_id를 NULL로 설정
  • Unique Constraints:
    • users.email - 이메일 중복 방지
    • esl_devices.mac_address - MAC 주소 유일성
    • (device_id, grid_position) - 디바이스 내 위치 중복 방지
    • (organization_id, sku) - 조직별 SKU 유일성
  • Check Constraints: 템플릿 호환성, 위치 유효성 검증
